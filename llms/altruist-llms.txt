# Altruist

> Altruist is a modern, vertically integrated RIA custodian and technology platform for independent financial advisors, combining self-clearing custody infrastructure with software for digital account opening, model-based trading, rebalancing, tax management, fee billing, and performance reporting. Its developer program exposes an OAuth 2.0 Open API and Realtime API (plus custodial flat-file feeds) so partners and advisor tools can automate account opening, money movement, and access account, position, transaction, and household data.

## APIs
- [Altruist Open API](https://developer.altruist.com/docs/altruist-open-api): OAuth2 authorization-code API for accounts, households, positions, transactions, and cost basis. Base URL https://openapi.altruist.com/altruist-open-api/
- [Altruist Realtime API](https://developer.altruist.com/docs/altruist-realtime-apis): OAuth2 password-grant API for account onboarding, funding, transfers, contacts, households, bank-link, and time-weighted return. Base URL https://integrations.altruist.com/api/
- [Altruist Custodial Flat Files](https://developer.altruist.com/docs/altruist-custodial-flat-files): SFTP flat-file delivery of household, account, position, transaction, and security data.
